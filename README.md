# Laundry Tales Website

A modern, responsive, mobile-first website for "Laundry Tales", a local laundry service business.

![Hero Preview](images/hero.png)

## 📌 Features

- **Responsive Design**: Works perfectly on mobile, tablet, and desktop.
- **Modern UI**: Clean aesthetics with white, light blue, and soft green colors.
- **Service Showcase**: Clear display of Washing, Dry Cleaning, and Ironing services.
- **Pricing Cards**: Easy to read pricing information.
- **Booking Form**: Simple frontend form for scheduling pickups.
- **Direct Contact**: Click-to-call and WhatsApp integration.
- **Reviews Section**: Highlighting customer testimonials and 4.9-star rating.
- **Fast Performance**: Optimized static HTML/CSS/JS with no heavy dependencies.

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your web browser.

## 🌐 How to Deploy to GitHub Pages

1. **Create a GitHub Repository**:
   - Go to [GitHub.com](https://github.com) and create a new repository.
   - Name it `laundry-tales` (or similar).

2. **Upload Files**:
   - Upload all files (`index.html`, `styles.css`, `script.js`, `README.md`, `images/`) to the repository.
   - You can do this via command line (`git push`) or using the GitHub web uploader.

3. **Enable GitHub Pages**:
   - Go to the repository **Settings**.
   - Click on **Pages** in the left sidebar.
   - Under **Source**, select `main` (or `master`) branch and `/` (root) folder.
   - Click **Save**.

4. **View Website**:
   - GitHub will generate a link (e.g., `https://yourusername.github.io/laundry-tales/`).
   - It may take a minute to go live.

## 🛠️ Customization

- **Colors**: Edit the variables in `styles.css` `:root` section.
- **Content**: Update text in `index.html`.
- **Images**: Replace images in the `images` folder.
